# CyberTwin — Frontend (Vue + Vite)

Interface du simulateur de risque cyber pour PME. Utilise une API Flask en backend.

## Libraries principales
- Vue 
- Vite
- Pinia
- Vue Router
- PrimeVue (UI)
- Axios
- jsPDF

## Prerequis
- Node.js version LTS et npm
- Le backend Flask CyberTwin demarre sur http://localhost:5000

## Installation
```bash
npm install
```

## Lancement
```bash
npm run dev
```

## Lien du projet en local
Ouvrir http://localhost:5173 après le lancement du projet.
